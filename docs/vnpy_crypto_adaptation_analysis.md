## 2) vn.py 典型架构拆解（用于定位改造点）

> 注：以下为框架级结构认知，具体代码位置在不同版本可能有差异。

1. **事件驱动核心（EventEngine）**
   - 负责 Tick、Order、Trade、Position、Account 等事件的总线分发。
   - 加密化改造影响：高频 websocket 增量事件、断线重连后的补偿事件、资金费率等新事件类型。

2. **交易主引擎（MainEngine）与网关层（Gateway）**
   - Gateway 抽象了交易所接入，实现统一的委托/撤单/查询接口。
   - 加密化改造影响：一个交易所通常同时提供 `Spot/USDT-M/COIN-M/Options` 多市场，需要网关支持多市场路由与统一符号语义。

3. **OMS 与账户模型**
   - 委托单、成交、持仓、账户资金通常以标准对象维护。
   - 加密化改造影响：保证金模式（全仓/逐仓）、多资产抵押、资金费率、杠杆层级、统一账户资产折算。

4. **CTA/策略层**
   - 通过 on_tick/on_bar/on_order/on_trade 驱动策略。
   - 加密化改造影响：7*24 交易、无收盘、跨交易所价差、永续合约与现货联动。

5. **行情与历史数据模块**
   - 负责 K 线、Tick 的订阅、回放、存储。
   - 加密化改造影响：加密交易所 K 线口径差异（开收盘定义、成交量单位、合约乘数）与补数逻辑。

## 3) 改造成“支持加密货币交易系统”的最小闭环

### 阶段 A：先打通交易链路（2~4 周）

1. **实现一个基准网关（建议先 Binance/OKX 二选一）**
   - REST：下单、撤单、查询订单/持仓/账户。
   - WS：行情订阅、私有推送（订单/成交/账户变更）。
   - 必做：签名、时间同步、限频器、断线重连、幂等去重。

2. **统一符号与交易单位**
   - 设计 `CryptoContractSpec`：
     - `symbol`（如 BTCUSDT）
     - `market_type`（SPOT/PERP/FUTURES/OPTION）
     - `price_tick`
     - `qty_step`
     - `min_notional`
     - `contract_size`
   - 所有策略侧使用统一字段，网关侧做双向映射。

3. **订单状态机增强**
   - 覆盖部分成交、多次成交回报、被动减仓、强平等状态。
   - 统一处理 `client_order_id` 以实现断线恢复后的关联。

### 阶段 B：补齐风控与清算语义（2~6 周）

1. **加密专用风控模块**
   - 单笔下单金额限制。
   - 单策略/单账户杠杆上限。
   - 波动率触发的动态限仓。

2. **保证金与盈亏计算引擎**
   - 支持现货与永续分开计量。
   - 支持资金费率入账、手续费返佣、跨币种折算。

3. **异常与容灾**
   - API 限频触发后的降级策略。
   - WS 中断自动切 REST 对账。
   - 冷启动后全量同步并重建本地状态。

### 阶段 C：策略与回测适配（并行推进）

1. **7*24 时钟模型**：去除 A 股式交易日假设。
2. **多交易所路由**：同一策略支持主交易所执行、次交易所对冲。
3. **回测数据规范化**：统一精度、手续费、滑点、资金费率模型。

## 4) 推荐的数据结构扩展（落地建议）

在原有对象模型上建议新增：

- `FundingRateData`：symbol、funding_rate、funding_time。
- `LiquidationData`：symbol、side、price、volume、timestamp。
- `MarginInfo`：account_id、margin_mode、leverage、maint_margin_ratio。
- `ExchangeStatusData`：交易所连接状态、限频状态、时间偏移。

这些对象应进入事件总线，便于策略、风控和监控统一订阅。

## 5) 网关实现中的关键工程点（最容易踩坑）

1. **时间同步与签名失效**：必须做本地与交易所 server time 偏移校准。
2. **精度与最小下单量**：应在下单前做量价裁剪（floor 到 step/tick）。
3. **重连去重**：同一成交可能由 REST 对账与 WS 回报重复出现，需要按交易所唯一成交 ID 去重。
4. **限频隔离**：行情、交易、查询应使用独立限频桶，防止互相挤占。
5. **统一错误码语义**：将交易所特有错误码归一到 `可重试/不可重试/风控拒单/参数错误`。
